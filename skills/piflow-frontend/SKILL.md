# piflow-frontend — Frontend Overlay

This is an overlay, not a standalone flow. Activated when task involves UI, React, Next.js, component API, design, or accessibility.

## When to Activate

- Task involves UI, components, pages, layouts
- React/Next.js implementation or performance
- Component API design or refactoring
- Accessibility or UX review

## Composition Rules

| Scenario                      | Skills to Apply               |
| ----------------------------- | ----------------------------- |
| New UI or visual redesign     | `frontend-design`             |
| React/Next.js implementation  | `vercel-react-best-practices` |
| Component API design/refactor | `vercel-composition-patterns` |
| UI review / accessibility     | `web-design-guidelines`       |

## Skills Referenced (by name)

`frontend-design`, `vercel-react-best-practices`, `vercel-composition-patterns`, `web-design-guidelines`

## Notes

- Overlay contains preferences but does NOT duplicate upstream skill docs.
- Skills are only injected when installed — missing skills are reported as warnings by `/pf-doctor`.
- Compose with any flow: `piflow-quick`, `piflow-full`, `piflow-refactor`.
