description: "PiFlow: отладка — параллельный диагноз → root cause → fix"
---

Запускает режим отладки с двумя параллельными подходами:

1. **Reproduce** — подтверждение воспроизводимости
2. **Parallel Diagnosis**:
   - systematic-debugging (Superpowers)
   - reproduce → minimise → hypothesise → instrument (Matt Pocock)
3. **Merge** — сравнение результатов
4. **Fix** — через piflow-quick

Жёсткое правило: никакого фикса до воспроизведения.

Ссылается на скилл: `piflow-debug`
